# 文献综述生成提示词

## 用途
基于多篇论文生成结构化的文献综述。

## 提示词模板

```
请基于以下论文列表，生成关于"{topic}"的文献综述。

论文列表：
{papers_list}

请按照以下结构组织综述：
1. 引言：介绍该研究领域的基本情况和重要性
2. 研究现状：概述当前的研究进展和主要研究方向
3. 方法分类：对不同研究方法进行分类和对比
4. 应用领域：总结主要应用场景
5. 挑战与展望：指出当前研究的挑战和未来发展方向

请确保综述内容：
- 准确反映论文内容
- 逻辑清晰，结构完整
- 使用学术语言
- 适当引用具体论文的观点
```

## 变量说明
- `{topic}`: 综述主题（字符串）
- `{papers_list}`: 论文列表（格式化后的论文信息）
