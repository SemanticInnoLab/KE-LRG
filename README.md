# Prompt Package

This folder bundles the prompt documentation and the actual prompt templates into one place for GitHub sharing.

## Contents

- `prompt_system_overview.md`: overall explanation of the prompt system
- `prompt_catalog.md`: categorized prompt inventory
- `00_baselines/`: baseline experiment prompts
- `01_knowledge_acquisition/`: prompts for retrieval, attribute extraction, and NormBank construction
- `02_knowledge_organization/`: prompts for outline generation and paper mounting
- `03_content_generation/`: prompts for section writing, abstract generation, and LCE refinement
- `04_knowledge_governance/`: prompts for claim audit, citation completion, and rewriting

All prompt files are copied from their current source locations so the package can be shared independently.
