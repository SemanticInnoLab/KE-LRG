# 论文摘要提示词

## 用途
对单篇或多篇论文生成摘要，提取关键信息和要点。

## 提示词模板

```
请对以下学术论文进行摘要，提取关键信息：

{paper_info}

请提供：
1. 研究问题：论文要解决的核心问题
2. 研究方法：使用的主要方法和技术
3. 主要贡献：论文的主要创新点和贡献
4. 关键结论：研究得出的主要结论

请用简洁、清晰的学术语言进行总结。
```

## 变量说明
- `{paper_info}`: 论文信息（包含标题、摘要、可能的关键章节等）

## 使用示例

```python
paper_info = f"""
标题: {paper['title']}
作者: {', '.join(paper.get('authors', []))}
摘要: {paper.get('abstract', '')}
"""
```
